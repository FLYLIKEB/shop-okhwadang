# 메일·알림톡 템플릿 관리

관리자 메뉴의 **설정 → 메일·알림톡**에서 템플릿을 편집합니다. 관리자와 최고 관리자만 조회·수정할 수 있으며, 공개 사이트 설정 API에는 노출되지 않습니다.

## 메일

- 주문 접수·취소, 결제 완료, 배송 시작, 문의 답변, 비밀번호 재설정, 이메일 인증, 재입고 알림의 한국어·영어 템플릿을 관리합니다.
- 제목, HTML 전체 문서와 일반 텍스트를 수정할 수 있습니다. 화면에 표시된 `{{변수명}}`을 사용하면 발송 시 고객·주문 정보로 치환됩니다.
- 주문 상품 목록은 `{{orderItemsHtml}}`과 `{{orderItemsText}}`를 사용합니다. 인증·비밀번호 재설정 링크 변수는 삭제할 수 없습니다.
- 미리보기는 저장 전 편집 내용을 가상 고객 정보로 렌더링해 새 창에 표시합니다. 실제 메일을 발송하지 않습니다. HTML은 스크립트 실행과 관리자 페이지 접근이 차단된 프레임에서 표시됩니다.
- 저장한 템플릿은 이후 렌더링되는 발송에 적용됩니다. 이미 발송한 메일은 변경되지 않습니다.

## 알림톡

- 주문 접수·취소, 결제 완료, 배송 시작·완료의 문구와 승인된 SOLAPI 템플릿 ID를 관리합니다.
- 본문 저장은 문자 대체 발송 문구에 적용됩니다. 카카오 알림톡 본문은 SOLAPI에 등록된 승인 템플릿에서 결정됩니다.
- 기존 템플릿 ID를 기준으로 수정본을 등록하고 검수를 요청할 수 있습니다. 수정본 검수 중에는 기존 발송 템플릿을 유지합니다.
- 승인 상태를 확인한 뒤 수정본 ID를 적용하고 저장해야 알림톡 발송에 반영됩니다. 최초 템플릿 및 채널 등록은 SOLAPI 콘솔에서 진행합니다.
- 관리 화면의 `{{변수명}}`은 수정본 등록 시 SOLAPI의 `#{변수명}` 형식으로 변환됩니다. 사용 가능한 변수명은 기존 발송 데이터와 일치해야 합니다.
- 검수·등록 기능에는 기존 SOLAPI API 인증 정보와 카카오 채널 설정이 필요합니다. 미리보기와 일반 저장은 메시지를 발송하지 않습니다.

공식 API: [템플릿 추가](https://solapi.com/developers/api/templates-createTemplate), [검수 요청](https://solapi.com/developers/api/templateManagement-requestTemplateInspection), [템플릿 조회](https://solapi.com/developers/api/templates-getTemplate).

## 배포

백엔드의 `CreateNotificationTemplates` TypeORM 마이그레이션을 적용한 후 새 백엔드를 시작합니다. 기존 템플릿은 기본값으로 유지되며, 관리자 저장 시 전용 테이블에 변경본이 저장됩니다. 실제 공급사 발송·검수 결과는 공급사 설정 및 승인 상태에 따라 달라집니다.
