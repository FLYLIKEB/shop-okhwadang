# 스마트스토어 상품 엑셀 import 지원 범위

## 지원 포맷

현재 관리자 상품 import는 아래 두 가지 XLSX 포맷을 공식 지원한다.

1. `smartstore-list-export`
   - 첫 번째 행이 실제 헤더
   - `상품번호(스마트스토어)`를 외부 상품번호로 인식
2. `smartstore-bulk-edit`
   - 시트명: `일괄수정`
   - 1행: 그룹 헤더
   - 2행: 실제 헤더
   - 3~5행: 안내/가이드
   - 6행 이후: 실제 상품 데이터

지원하지 않는 포맷이나 필수 컬럼이 빠진 파일은 예상 포맷과 누락 컬럼을 포함한 오류 메시지로 거절한다.

## 식별자 우선순위

동일 상품 판별은 아래 순서를 따른다.

1. `판매자 상품코드`
2. 값이 없으면 스마트스토어 상품번호를 `naver-{상품번호}` 형태로 변환한 외부 식별자

파일 안에서 같은 식별자가 중복되면 해당 행은 스킵된다.

## 상태 매핑

`상품상태`는 `신상품`, `중고상품` 같은 상품 속성값이므로 자사몰 판매 상태 계산에 사용하지 않는다.

자사몰 `ProductStatus`는 아래 의미만 사용한다.

- `판매중` + 재고 있음 → `active`
- `판매중` + 재고 0 → `soldout`
- `품절` → `soldout`
- `전시중지`, `판매중지`, `숨김` → `hidden`
- 기타 값 → 재고 기준 기본값

## 현재 반영 범위

현재 1차 import는 기본 상품 필드 중심이다.

- 지원: 식별자, 상품명, 판매가, 할인가, 재고, 상태, 대표 이미지, 기본 설명 필드
- 후속 과제: 옵션, 상세 이미지 확장, 복잡한 추가 이미지/옵션 조합 처리

관리자 UI의 안내 문구와 이 문서는 같은 범위를 설명해야 한다.
