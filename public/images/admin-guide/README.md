# 어드민 가이드 스크린샷

- 촬영일: 2026-10-12
- 출처: 이 저장소의 실제 어드민 페이지·폼 컴포넌트
- 데이터: 촬영 전용 예시 데이터. 운영 고객 정보, 인증 정보, 실제 주문은 포함하지 않습니다.
- 화면: 한국어, 라이트 테마, 이미지 1280 × 800 (긴 폼은 더 높은 뷰포트에서 필요한 영역을 촬영)
- 형식: WebP. 원본 화면의 문구·컨트롤을 합성하거나 AI로 재작성하지 않았습니다.

`src/lib/admin-guide.ts`의 `ADMIN_GUIDE_SCREENSHOTS`에서 슬라이드와 이미지를 연결합니다.
같은 화면에서 이어지는 설명은 같은 이미지를 사용하고, 편집·미리보기 등 화면이 바뀌는 설명은 별도 이미지를 사용합니다.

UI가 바뀌면 해당 페이지를 예시 데이터로 다시 촬영하고 파일을 교체하세요.
이미지에는 고객 개인정보·실제 로그·토큰·접속 정보를 넣지 마세요.

팝업 목록·편집 화면은 2026-10-23에 예시 데이터로 촬영했습니다. 팝업은 홈에서 노출되며 새 등록은 비활성 상태입니다. 활성화 여부와 게시 기간을 확인한 뒤 저장하세요. 날짜는 브라우저 현지 시간 기준이고, 오늘 하루 숨기기는 방문자의 브라우저에 저장됩니다.

쿠폰·회원 등급 점검(#1290) 후 쿠폰 목록·편집·발급, 규칙, 회원 목록 이미지를 재촬영했습니다. 규칙 조건 슬라이드는 현재 등급 조건과 생일 규칙 제한이 보이는 목록 이미지를 함께 사용합니다.

대시보드 기간 필터 수정(#1293) 후 2026-10-13에 기간 지표·누적 지표 안내 화면을 재촬영했습니다.
